# Primary analysis: 28 held-out tasks, scoring v2

These are the results reported in the manuscript.

- **Tasks:** the 28 synthetic held-out tasks (T01–T28). Task T29, a full audit of a ten-note pilot case, is excluded from the primary analysis because the pilot's provenance could not be verified. T29 remains in `evaluation/tasks/tasks_heldout.json` so task numbering is unchanged.
- **Scoring:** v2 (`evaluation/scoring/aggregate.py`). Task F1 = 2TP/(2TP+FP+FN) per run, which is 0 when no reference finding is detected, including missing reports. Clean tasks score 1 only for a submitted report asserting no in-scope finding. Precision is undefined when nothing is asserted. Trials are averaged within each task, and 95% CIs use a 2,000-resample task-level bootstrap (seed 0) with paired resampling for differences.

| File | Content |
|---|---|
| `scores_runs.csv` | Run-level scores for the 28 synthetic tasks: 196 runs (checklist 28, each agent condition 84). Each row holds finding-code sets, counts, timings and token totals. There is no clinical content, and no rows from the restricted pilot or the real extraction run. |
| `scores_summary.json` / `.md` | Aggregate output of `aggregate.py` on this CSV |
| `tables/*.tex` | Manuscript tables generated by `manuscript/make_tables.py` from this directory |

## Reproduce (CPU only, public repository alone)
```bash
cd part_b_agentic_audit
python evaluation/scoring/aggregate.py --scores-csv manuscript/corrected_28_tasks/scores_runs.csv \
    --tasks evaluation/tasks/tasks_heldout.json --exclude-task T29 --out-dir manuscript/corrected_28_tasks
python manuscript/make_tables.py --in-dir manuscript/corrected_28_tasks --out manuscript/corrected_28_tasks/tables
```

The run-level CSV was produced by re-scoring the original saved agent run directories with scoring v2 (`aggregate.py --exp EXP_heldout --exclude-task T29`) on the authors' server. Those run directories (tool logs, reports, OpenClaw state) are not distributed, so re-scoring *from raw runs* requires them. Aggregating from the CSV reproduces the summary exactly; this was verified by comparison with the summary re-scored from raw runs.
