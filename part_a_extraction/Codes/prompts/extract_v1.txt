Return ONLY a single JSON object that follows this schema exactly:

{
  "symptoms": [string, ...],
  "diagnoses": [string, ...],
  "medications": [string, ...],
  "assessment_summary": string,
  "evidence": [
     {"field": "symptoms|diagnoses|medications|assessment_summary", "item": string, "quote": string},

  ]

- Do not include any keys other than the schema keys.
- Arrays must be arrays of strings (not dicts, not nested objects).

- Do not output raw quotes from the note in JSON; always Base64-encode them.
